Gardener

Gardener is a lightweight front-end library for creating and manipulating DOM elements using a clean, declarative JavaScript object syntax.

It comes with a development server featuring hot reload, on-the-fly component creation from existing HTML, dynamic image resizing & caching, and zero virtual DOM / JSX / build-step philosophy.

npm create gardener Try it now
github.com/ritishDas/gardener

Design Philosophy

  • No virtual DOM
  • No JSX
  • No compilation / build step
  • DOM-first and fully deterministic
  • Everything is explicit and inspectable in the browser

Core Utilities

DOM Helpers

  • fetchElement(selector) — safe querySelector wrapper
  • appendElement(parent, child) — append child node
  • replaceElement(oldElement, newElement) — replace DOM node
  • createElement(type, classes) — low-level element factory
  • imagePreloader(images) — preload images efficiently

Gardener – The Declarative Builder

gardener({
  t: 'div',
  cn: ['p-6', 'flex', 'gap-4'],
  attr: { id: 'hero', role: 'banner' },
  txt: 'Welcome',
  events: {
    click: () => console.log('clicked!')
  },
  children: [ /* nested objects */ ]
})
Key Description
t HTML/SVG tag name
cn Array of class names
attr Attributes / properties object
txt Text content (string)
eventsEvent listeners { event: handler }
childrenArray of nested gardener objects

Runtime Configuration

const config = {
  mode: 'dev',           // 'dev' | 'prod'
  componentdir: 'components',
  hotreload: true
}
  • mode: dev → enables parser, hot reload, dev UI; prod → disables everything
  • componentdir: folder for auto-generated component files
  • hotreload: persisted in localStorage

Hot Reload (Dev Mode)

  • State saved in localStorage
  • Auto-reload after ~1 second when enabled
  • Disabling cancels pending timers

Toggle shortcut: Ctrl + H

SVG Support

Gardener automatically uses the SVG namespace for these tags: 

svg, path, circle, rect, line, polygon, polyline, g, defs, clipPath, use

All attributes are applied via setAttribute safely.

Creating Components

  1. Write normal HTML + classes (give parent an id or unique selector)
  2. Run: parser(fetchElement('#your-id'))
  3. Popup appears → choose component name
  4. File saved to /src/frontend/components/YourName.js

Using Components

import { myHeader } from '/components/myHeader.js'

replaceElement(
  fetchElement('#header-placeholder'),
  myHeader()
)

Image Optimization & Caching

  • Place originals in /src/frontend/assets/
  • Use: <img src="/cache/photo_800x600.webp">

Server auto-converts to WebP, resizes, and caches on demand.
